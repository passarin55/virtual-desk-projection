    OUTPUT · CORNER PIN

    Drag the four handles until the projected frame sits exactly on your desk area (turn on the mm grid). Arrow keys nudge the selected corner by 1 px, Shift×10.

    OUTPUT · LIGHT

    Tint compensates a coloured desk: lower the channels your surface over-reflects (a warm wood desk → lower red).

    CAMERA ↔ DESK · GRAY CODE

    Projects black, white and bit-plane stripes (each with its inverse), decodes every camera pixel, fits a RANSAC homography. SIM CAM runs a synthetic tilted camera with lens distortion so you can see the solver work and score it against ground truth.

    TOUCH ACCURACY

    Nine rings appear on the desk; tap each centre with the input you use (finger on depth, AIR pinch, mouse). The mean offset is removed automatically and the remaining spread sets the safe target size.

    LATENCY PROBE

    Flashes a square and times how long the (calibrated) webcam takes to see it: render + projector lag + camera.

    AIR INPUT · WEBCAM HANDS

    MediaPipe Hand Landmarker in the browser. A single RGB camera cannot see contact, so pressing is a pinch (or a dwell). Needs the camera calibration above.

      RUN THE HOST

      The host injects keys, mouse and touch into your OS, reads the focused window, streams windows into the PORTAL and runs the depth-touch engine. It serves this page at 127.0.0.1 and opens it with a per-run token in the link (…/#t=…): the fragment never reaches a server or a log, and the page itself never contains it. On another device (LAN mode) open the LAN link the host prints, or paste the token here. This page opened from disk connects only after "allow_file_origin": true in ~/.tabula/config.json.

      pip install websockets numpy opencv-contrib-python psutil "mss>=10" pillow
python tabula_host.py                     # safe: starts disarmed
python tabula_host.py --dry-run --sense synthetic   # try everything, inject nothing
python tabula_host.py --sense realsense   # or orbbec · k4a · freenect2 · lightplane:1
python tabula_host.py --print-tokens tokens.svg     # ArUco MIP 36h12 tokens

      Optional per-OS extras: Windows pycaw dxcam · Linux evdev (+ uinput access) · macOS pyobjc-framework-Quartz · MIDI mido python-rtmidi.
